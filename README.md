**# Shop Management System in C**



**A console-based Inventory and Billing Management System developed using the C programming language.**



**## Features**



**- Add, view, search and delete products**

**- Update product prices and stock quantities**

**- Prevent duplicate product IDs**

**- Input validation**

**- Support product names containing spaces**

**- Generate bills containing multiple products**

**- Automatic inventory deduction after purchases**

**- Low-stock alerts**

**- Persistent product storage using file handling**

**- Transaction history with timestamps and transaction IDs**

**- Daily sales reports**

**- Lifetime revenue tracking**



**## Technologies Used**



**- C Programming**

**- Structures**

**- Arrays**

**- Functions**

**- Pointers**

**- File Handling**

**- Standard C Libraries**



**## How to Run**



**1. Clone or download this repository.**

**2. Open the project folder.**

**3. Compile the source code using GCC:**



&#x20;  **```bash**

&#x20;  **gcc main.c -o inventory**

&#x20;  **```**



**4. Run the executable:**



&#x20;  **\*\*Windows:\*\***

&#x20;  **```bash**

&#x20;  **inventory.exe**

&#x20;  **```**



&#x20;  **\*\*Linux/macOS:\*\***

&#x20;  **```bash**

&#x20;  **./inventory**

&#x20;  **```**



**## Data Storage**



**The application automatically creates and updates these files:**



**- `products.txt` – Stores product information and total revenue.**

**- `sales\_history.txt` – Stores completed transaction records.**

**- `daily\_sales.txt` – Stores daily sales information.**



**These files are generated when the application runs.**
